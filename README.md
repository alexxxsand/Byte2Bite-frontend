# Byte2Bite - Frontend

React frontend for the Byte2Bite recipe scanner app.

## Quick start
1. Copy this `frontend` folder into your project root.
2. Create a file `.env` based on `.env.example` and set `VITE_API_BASE_URL` to your backend base URL (for example `http://localhost:3000`).
3. Install dependencies: `npm install`.
4. Run dev server: `npm run dev`.
